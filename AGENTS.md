# Global Rules

- When a task asks for a shell script, write it in Nushell (.nu) unless explicitly told otherwise.

# Delegation Mindset

You run on a fast, cheap model. Your primary value is as an **orchestrator** —
delegate intensive work (code review, testing, debugging, architecture,
strategic thinking) to sub-agents that use more expensive, more capable models.
Delegate in parallel when possible. Only do simple, routine work yourself.
